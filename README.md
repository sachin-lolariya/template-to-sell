# Aether Atelier // High-Converting Social Architecture & Creative Studio Template

A commercial-grade, luxury website template built for creative studios, social media architecture ateliers, high-growth consumer brands, and modern marketing agencies. Engineered for commercial sale on Webflow, Framer, and ThemeForest.

## ✨ Tech Stack & Features
- **Semantic HTML5**: Clean, SEO-optimized markup with complete ARIA accessible landmarks and zero framework bloat.
- **Fluid CSS3 Design System**: Bespoke luxury palette (Platinum Alabaster `#F8FAFC`, Obsidian Charcoal `#0A0D14`, Electric Royal Cobalt `#2563EB`, High-Voltage Citron `#D9FE38`).
- **GSAP 3 & ScrollTrigger**:
  - The Attention Manifesto word-by-word scroll-linked scrub illumination (`#manifesto`)
  - Smooth section timeline reveals and tactile micro-interactions
  - Rule 5 card hover elevation and contained image scaling (1.035x)
- **Interactive Modules**:
  - **Flagship Case Studies** (`#work`): 4 bespoke editorial brand case decks with verified metrics (+340% wholesale inquiries, 1.4M organic views)
  - **The Content Lab & ROI Simulator** (`#the-lab`): Dynamic platform & industry matrix with real-time video simulation and audience telemetry
  - **Unedited Group Chat Testimonials** (`#testimonials`): Unfiltered screenshot-style client DM threads with interactive switching across Harriet, Aiko, and Leila
  - **Audience Performance Telemetry** (`#performance`): High-contrast live data board showcasing 140M+ impressions and verified enterprise value
  - **Transparent Retainers** (`#pricing`): Predictable tiers with interactive Monthly vs Quarterly (-15%) calculation
  - **Clarity & Terms FAQ** (`#faq`): Smooth animated accordion addressing IP ownership, turnaround time, and camera direction
  - **Interactive Scope Builder** (`#contact`): Multi-select project brief with instant transmission feedback
- **Zero Copyright Risk**: 100% original creative concepts, naming conventions, and layout structures designed specifically to sell on Framer and Webflow.
- **PHP + Netlify Backend Pipeline**: `api/contact.php` for asynchronous lead persistence.
- **Zero Framework Bloat**: Pure vanilla HTML5, CSS3, JavaScript & GSAP 3 — lightweight, blazing fast, and instantly portable.
