# Aether Atelier // High-Converting Social Architecture & Creative Studio Template

A commercial-grade, luxury website template built for creative studios, social media architecture ateliers, high-growth consumer brands, and modern marketing agencies. Engineered for commercial sale on Webflow, Framer, and ThemeForest.

## ✨ Tech Stack & Features
- **Semantic HTML5**: Clean, SEO-optimized markup with complete ARIA accessible landmarks.
- **Fluid CSS3 Design System**: Bespoke luxury editorial palette (Warm Alabaster, Obsidian Charcoal, Radiant Vermilion, High-Voltage Citron).
- **GSAP 3 & ScrollTrigger**:
  - The Editorial word-by-word scroll-linked scrub illumination (`#manifesto`)
  - Smooth section timeline reveals and micro-interactions
  - Rule 5 card hover elevation and contained image scaling
- **Interactive Modules**:
  - **Group Chat Client Testimonials** (`#group-chat`): Unedited screenshot-style client DM threads with interactive switching across Harriet, Aiko, and Leila
  - **Case Notes Slider** (`#case-studies`): Responsive carousel with smooth previous/next navigation and drag-to-scroll support
  - **Post Time Machine** (`#post-time-machine`): 7-day social content calendar inside an iPhone mockup with dynamic industry switching (Fashion, Food, Tech, Beauty, Fitness, Lifestyle)
  - **Platform Weather Playground** (`#platform-playground`): Interactive tabs for Instagram, TikTok, YouTube, and LinkedIn
  - **Hot Take Generator** (`#hot-takes`): Instant industry quote shuffle and one-click clipboard copy
  - **Interactive DM FAQ System** (`#faq`): Direct-message chat consultation interface with live typing feedback
- **PHP + Netlify Backend Pipeline**: `api/contact.php` for asynchronous lead persistence.
- **Zero Framework Bloat**: Pure vanilla HTML5, CSS3, JavaScript & GSAP 3 — lightweight, blazing fast, and instantly portable.

## 🚀 Local Development

```bash
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
