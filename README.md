# Updraft // High-Converting Creative & Social Media Agency Template

An ultra-premium, production-ready website template crafted for creative studios, social media agencies, content collectives, and modern marketing firms.

## ✨ Tech Stack & Features
- **Semantic HTML5**: Clean, SEO-optimized markup with accessible ARIA landmarks.
- **Fluid CSS3 Design System**: Custom luxury color scheme, typography scales (Inter, DM Mono, Magra, Instrument Serif), and responsive utility classes.
- **GSAP 3 & ScrollTrigger**: Smooth timeline reveals, card hover micro-interactions, and organic entrances.
- **Interactive Modules**:
  - Live Ticker Marquee (`#culture-index`)
  - Platform Weather Filter (`#platform-playground`) - TikTok, Instagram, YouTube, LinkedIn
  - Category Portfolio Filters (`Fashion`, `Food`, `Tech`, `Beauty`)
  - Hot Take Generator (`#hot-takes`)
  - FAQ Accordion (`#faq`)
- **PHP Backend**: `api/contact.php` for newsletter subscriptions and client inquiries.
- **Zero Framework Bloat**: No complex bundlers needed — opens directly in any browser or static host.

## 🚀 Getting Started
### Local Development
```bash
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Deployment
Ready to deploy in 1 click on **Netlify**, **Vercel**, **GitHub Pages**, or traditional **cPanel/Apache/Nginx** hosting.
